# IRQScope local evaluation matrix

This matrix records what the current workspace has actually checked. Pure-Python and mocked-IDAPython checks are not substitutes for loading the plugin into IDA or analyzing the ELF fixtures there.

## Reproduction commands

Run from the repository root:

```sh
python -m compileall -q irqscope irqscope_plugin.py tests tools
ruff check irqscope tools tests irqscope_plugin.py
python -m unittest discover -s tests -v
python tools/build_demo.py --check
```

For a package lint, build with real project metadata:

```sh
python tools/package_release.py --github-repository https://github.com/<owner>/<repo> --author "<author name>" --author-email "<author email>"
hcli plugin lint dist/irqscope-0.1.0.zip
```
